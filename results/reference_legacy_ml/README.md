## Main Comparison Files

These are the organized control/experimental ML comparison artifacts requested for the paper-style ML reference:

- `legacy_ml_comparison_performance_long.csv`: tidy table with 90 rows across all ML models, K/interval conditions, and control/experimental groups.
- `legacy_ml_comparison_performance_wide.csv`: one row per model and condition, with control, cluster group, and summed-cluster metrics in columns.
- `legacy_ml_comparison_provenance.json`: source paths, SHA-256 hashes, duplicate-source checks, metric order, and Korean label mapping.
- `comparison_raw/`: exact copied raw `ELEC_Comparison_{MODEL}_{K}{INTERVAL}.txt` files for `CB`, `DT`, `LGBM`, `RF`, and `XGB`.

The extracted metric order is:

`MAE`, `MAPE`, `MSE`, `RMSE`, `MSLE`, `MBE`, `R2`
